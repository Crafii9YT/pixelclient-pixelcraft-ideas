# Submit Pull Requests

Submit Pull Requests like this:

1. Fork the Repository.
2. Add an Folder (name it after the mod name) with an README.md with an little description about what your adding.
3. Upload the .JAR file that you want to submit.
4. Open an Pull Request.

Finished!

## Note for modders

If your mod is self-made, please tell us in the PR.

Self-Made Mods are getting reviewed manually, and credited in the Mods Menu.
